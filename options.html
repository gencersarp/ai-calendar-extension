Why do I need an API Key?
This extension uses Google's AI (Gemini) to understand the event text. To use Google's AI services, an API key is required. By providing your own free key, the AI usage counts towards your personal free quota, keeping this extension free to use. Your key is stored securely only within your browser's local storage for this extension.

How to get your key:
1. Visit the Google AI Studio API Key page.
2. Sign in with your Google Account.
3. Click "Create API key in new project" (or existing one).
4. Copy the generated API key (it's a long string of letters and numbers).
5. Paste it into the box below and click "Save Key".
